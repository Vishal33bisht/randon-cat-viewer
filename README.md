# 🐱 Random Cat Viewer

Random Cat Viewer is a simple web application that displays random cat images using a public Cat API. The project is built with HTML, CSS, and JavaScript and is ideal for beginners learning API handling and frontend development.

---

## 🚀 Features

- View random cat images instantly
- Clean and responsive user interface
- Fast and lightweight application
- Beginner-friendly project structure

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Cat API

---

## 📂 Files

```bash
index.html   # Main webpage structure
style.css    # Styling and layout
script.js    # Fetch API and functionality
```

---

## ⚡ How It Works

1. User opens the application
2. JavaScript sends a request to the Cat API
3. API returns a random cat image
4. Image is displayed on the screen

---

## ▶️ Run Locally

```bash
git clone https://github.com/Vishal33bisht/randon-cat-viewer.git
cd randon-cat-viewer
```

Then open `index.html` in your browser.

---

## 🔗 API Used

```bash
https://api.thecatapi.com/v1/images/search
```
